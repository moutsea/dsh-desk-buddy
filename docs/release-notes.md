# dsh-desk-buddy 0.14.2

新增 8 种离线声线和会话用量统计，并完善并发更新、重连及音频加载时的处理。

## 新功能

- **8 种可选女声**：俏皮少女、软萌甜心、元气甜妹、清甜纯净、轻柔治愈、灵动自然、温柔邻家、轻柔气声。支持试听、音量和三个场景的独立开关。
- **离线语音提示**：摸摸回应、任务完成、闲置招呼和试听共 32 段 Qwen TTS 音频，随应用打包，播放无需联网或配置密钥。
- **会话用量**：累计 Token、输入缓存命中率、上下文占用，以及可展开的输入输出、生成速度、首字耗时和轮次明细。
- **更简洁的项目首页**：补充真实界面截图，详细使用和开发说明移至文档。

## 修复

- 统计按指标序号合并，避免旧缓存、重复事件和历史分页覆盖新数据；断线重连重新获取完整快照。
- 修复多个请求乱序返回时数值纠正、指标移除或恢复失效的问题，同时保留更高序号的实时统计。
- 持续流式输出不再阻塞统计刷新或后台任务完成提醒。
- 完成音加载期间调整音量不再丢失提醒；切换连接、声线、静音会取消失效播放，普通会话切换保留后台提醒。
- 音频读取、解码和设备唤醒有超时保护，失败后可重新试听；迟到的请求不会覆盖新试听状态或误报错误。
- 切换声线后等待设置同步到播放器再开放试听，避免快速操作时播放旧声线或漏播。
- 修复窗口首次显示时动画偶发停顿，以及迟到的可见性查询覆盖新窗口状态的问题。
- 首次挂载及时同步系统动态效果偏好，避免初始化期间偏好变化后动画状态未更新。

## 安装与升级

在 DSH Desktop「插件 → 添加插件」填写 `https://github.com/moutsea/dsh-desk-buddy`，启用后重启 DSH。也可使用下方完整 `.tgz` 附件链接或本地绝对路径，无需另装 Node.js、Electron 或启动 DSH Web。

- `darwin-arm64`：macOS Apple Silicon。
- `win32-x64`：Windows x64。
- `SHA256SUMS.txt`：两个完整插件包的校验值。

已有用户可在「设置 → 插件更新」检查并更新，升级后重启 DSH。旧版本迁移见 [插件说明](https://github.com/moutsea/dsh-desk-buddy/blob/main/plugins/dsh-girl/README.md)。

发布前在 macOS ARM64 和 Windows x64 执行单元检查、安装、打包及桌面交互回归，包括用量和音频测试。检查使用隔离数据，不调用模型。官方 DSH Desktop 宿主全流程验证范围仍以 [平台文档](https://github.com/moutsea/dsh-desk-buddy/blob/main/docs/platforms.md) 为准；当前成品未签名，macOS 未公证。

# dsh-desk-buddy 0.17.3

历史消息读取和断线恢复更可靠，翻页与流式回复保持阅读位置，表情预览和语音缓存占用更少内存。

## 界面与交互

- **翻页保持阅读位置**：加载更早的消息、流式回复完成、补齐回复前缀和调整窗口大小时，继续定位到正在阅读的文字；隐藏后恢复聊天也保留位置。
- **尊重跟随选择**：加载旧页后暂停跟随新消息，手动滚到底部或发送消息后恢复跟随。重连补读失败时，仍可加载旧页并保持阅读位置。
- **更轻的表情预览**：表情页和对话头像使用缩略图，桌宠本体保留原图；限制已解码的语音缓存，减少切换声线后的内存占用。

## 修复与可靠性

- DSH 重连后逐页补齐断线期间的消息缺口；读取失败会重试，加载旧页不会误清最新历史的恢复状态。
- 隔离旧连接、旧会话和历史重置前的请求，避免迟到结果覆盖当前内容；首次加载失败后恢复已选会话。
- 保留流式回复与最终消息的关联，处理重复文本、多文本块、Markdown 格式和回复前缀补读，避免重复显示或跳到错误段落。
- 新建会话后的辅助读取失败不再掩盖创建成功；发送失败、会话移除或连接恢复时保留并恢复未发送草稿。
- 修复会话移除与重新出现、任务完成状态和后台列表读取的竞态，避免旧状态重新出现。
- 增加历史列表的无界面浏览器回归和共享 JavaScript 类型检查，并纳入 Windows x64 与 macOS ARM64 的验证流程。

## 安装与升级

在 DSH Desktop「插件 → 添加插件」填写 `https://github.com/moutsea/dsh-desk-buddy`，启用后重启 DSH。已有用户可在「设置 → 插件更新」检查并更新，升级后重启 DSH。

也可使用本页完整 `.tgz` 附件链接或本地绝对路径，无需另装 Node.js、Electron 或启动 DSH Web：

- `darwin-arm64`：macOS Apple Silicon。
- `win32-x64`：Windows x64。
- `SHA256SUMS.txt`：两个完整插件包的校验值。

Codex 接入需要自行启动并连接共享 App Server，不会接管已有独立窗口的任务。成品未签名，macOS 未公证；平台验证范围见 [平台说明](https://github.com/moutsea/dsh-desk-buddy/blob/main/docs/platforms.md)。

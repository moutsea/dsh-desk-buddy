# dsh-desk-buddy 0.17.1

声音设置更简洁，管理弹窗更容易收起，更新后的状态提示更清楚。

## 界面与交互

- **互动声音设置弹窗**：设置页保留声音总开关、声线和音量，13 类场景的独立开关与试听收进弹窗。支持滚动查看、键盘操作，点击弹窗外、关闭按钮或按 Esc 返回设置页。
- **DSH 管理弹窗**：自动选择按钮上方或下方的空间展开，避免遮挡入口；点击外部或按 Esc 即可收起。
- 更新声音设置截图和使用说明。

## 修复与可靠性

- 修复升级时服务返回空响应造成的 JSON 解析错误，改为可理解的服务状态提示。安装完成后保留“等待重启 DSH”，避免旧页面继续轮询已移除的路由或执行失效操作。
- 修复声音弹窗打开、关闭、隐藏恢复，以及切换页面时的鼠标穿透；鼠标不移动也能正确恢复交互，迟到的光标查询不会覆盖新的操作。
- 增加静止鼠标、隐藏恢复和光标查询并发的回归测试，隔离自动测试中的原生鼠标事件干扰；沿用两平台打包验证和成品校验发布流程。

## 安装与升级

在 DSH Desktop「插件 → 添加插件」填写 `https://github.com/moutsea/dsh-desk-buddy`，启用后重启 DSH。已有用户可在「设置 → 插件更新」检查并更新，升级后重启 DSH。

也可使用本页完整 `.tgz` 附件链接或本地绝对路径，无需另装 Node.js、Electron 或启动 DSH Web：

- `darwin-arm64`：macOS Apple Silicon。
- `win32-x64`：Windows x64。
- `SHA256SUMS.txt`：两个完整插件包的校验值。

Codex 接入需要自行启动并连接共享 App Server，不会接管已有独立窗口的任务。成品未签名，macOS 未公证；平台验证范围见 [平台说明](https://github.com/moutsea/dsh-desk-buddy/blob/main/docs/platforms.md)。

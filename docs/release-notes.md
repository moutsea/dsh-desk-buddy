# dsh-desk-buddy 0.17.2

进度气泡更容易查看和关闭，插件卸载失败后能够恢复旧版。

## 界面与交互

- **稳定的气泡关闭按钮**：鼠标悬停只强调指向的卡片，不再切换会话或重排卡片。关闭后会重新检查静止指针下的补位卡片，连续点击 × 不会误打开其他会话。
- **清晰的进度预览**：悬停后层卡片时淡化其他卡片，避免前层选中卡片遮挡正文；键盘浏览继续突出选中的卡片。
- **会话列表关闭入口**：每行可单独关闭对应气泡，不停止任务、不删除会话，也不收起列表。
- 折叠会话通过方向键、Home / End 翻看，Tab 可移动到选中气泡的关闭按钮。

## 修复与可靠性

- 插件更新遇到卸载失败且旧安装仍存在时，直接重新启用旧版，避免重复执行失败的包管理操作。
- 针对依赖锁文件不完整和依赖发布时间限制提供明确提示；恢复失败时保留失败原因，不把包管理器的原始诊断内容展示到页面。
- 更新操作失败后保留错误提示，不再被后台状态轮询清除；用户重试成功后清除提示。
- 新增无界面浏览器回归测试，覆盖连续关闭、浅色与深色预览、透明空隙和键盘关闭，并纳入两平台 CI；扩展官方宿主卸载失败恢复检查。

## 安装与升级

在 DSH Desktop「插件 → 添加插件」填写 `https://github.com/moutsea/dsh-desk-buddy`，启用后重启 DSH。已有用户可在「设置 → 插件更新」检查并更新，升级后重启 DSH。

也可使用本页完整 `.tgz` 附件链接或本地绝对路径，无需另装 Node.js、Electron 或启动 DSH Web：

- `darwin-arm64`：macOS Apple Silicon。
- `win32-x64`：Windows x64。
- `SHA256SUMS.txt`：两个完整插件包的校验值。

Codex 接入需要自行启动并连接共享 App Server，不会接管已有独立窗口的任务。成品未签名，macOS 未公证；平台验证范围见 [平台说明](https://github.com/moutsea/dsh-desk-buddy/blob/main/docs/platforms.md)。

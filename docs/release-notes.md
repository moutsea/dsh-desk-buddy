# dsh-desk-buddy 0.15.0

让桌边陪伴更丰富：8 种声线扩充至 208 段离线语音，覆盖 13 类场景，互动和工作提醒都有随机台词。

## 新功能

- **更多互动回应**：连点闹小脾气、久看害羞、睡醒、入睡、久别重逢、拖动放下，以及断线后的恢复连接提示。
- **更丰富的工作提醒**：开工、等待审批或回答、任务完成和任务失败都有语音；摸摸、闲置及这四类工作提醒各有三句随机台词，不连续重复。
- **13 类场景独立控制**：支持单独开关和试听；开工、入睡、拖动放下、恢复连接默认关闭，既有静音偏好在升级时保留。
- **208 段离线音频**：8 种女声完整覆盖所有场景，随应用打包，播放无需联网、密钥或额外模型调用。
- **更新图文说明**：补充声音设置截图与使用说明，并在 README 加入赞助商 [Kimiseek](https://kimiseek.app)：国模五折起。

## 修复

- 同一次任务失败的主机错误和结束事件只提醒一次，重复事件不会重播；新的独立错误仍能正常提醒。
- 失败语音加载或播放期间，迟到的任务输出不再误取消提醒；新一轮任务或连接失效会正确停止旧提示。
- 提示按优先级和有效期处理，避免互动打断重要工作提醒，或拖动结束、断线重连的迟到回调触发过期语音。
- 欢迎、睡醒与恢复连接分别按实际状态触发，避免短暂隐藏、快速重连或多次点击重复播报。
- 补充加载中、播放中、事件乱序、去重和场景切换的自动回归测试。

## 安装与升级

在 DSH Desktop「插件 → 添加插件」填写 `https://github.com/moutsea/dsh-desk-buddy`，启用后重启 DSH。也可使用下方完整 `.tgz` 附件链接或本地绝对路径，无需另装 Node.js、Electron 或启动 DSH Web。

- `darwin-arm64`：macOS Apple Silicon。
- `win32-x64`：Windows x64。
- `SHA256SUMS.txt`：两个完整插件包的校验值。

已有用户可在「设置 → 插件更新」检查并更新，升级后重启 DSH。旧版本迁移见 [插件说明](https://github.com/moutsea/dsh-desk-buddy/blob/main/plugins/dsh-girl/README.md)。

发布前在 macOS ARM64 和 Windows x64 执行单元检查、安装、打包及桌面交互回归，包括用量和音频测试。检查使用隔离数据，不调用模型。官方 DSH Desktop 宿主全流程验证范围仍以 [平台文档](https://github.com/moutsea/dsh-desk-buddy/blob/main/docs/platforms.md) 为准；当前成品未签名，macOS 未公证。

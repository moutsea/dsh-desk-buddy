# dsh-desk-buddy 0.16.0

让并行任务一眼看清：同时进行或等待你回应的会话会叠成一摞进度卡片，可以沿斜向翻看。

## 新功能

- **多会话进度卡片**：所有进行中或待回应的会话都会显示，最多同时出现 5 张，向后上方 45° 等距叠放；后层只露出标题条，正文保持水平。
- **折叠与翻看**：超过 5 个会话时，静止状态保留首尾和当前会话，中间折叠；悬停后沿斜向前后移动即可轮动切换，鼠标停下不再继续跳，也可用方向键和 Home / End。
- **点击直达**：点哪张卡片就打开哪个会话，按回车打开当前选中的会话；流式更新不会让卡片重排，会话结束后卡片自动移除。
- **贴边不挡角色**：桌宠靠近屏幕顶部时按上方可用高度少显示几张（至少保留 1 张），卡片和计数条都不会盖到角色头顶，摸摸和拖动照常可用。
- **读屏可读**：卡片的可访问名称包含标题、状态和实时预览，绘制副本对辅助技术隐藏；键盘焦点只落在当前卡片上。

## 修复

- 修复多个会话先后结束或改变状态时桌宠闪一下的问题：切换表情时保留上一张已解码的精灵继续绘制，新图就绪后单帧替换，不再出现空白帧。
- 修复点击卡片可能打开另一条会话的问题：绘制层与命中层使用同一层级，指针命中的始终是看到的那张卡。
- 透明窗口显式设置透明底色，避免重新合成时露出白底。
- 卡片之间的空隙恢复桌面点击穿透，桌宠区域不再拦截桌面操作。

## 安装与升级

在 DSH Desktop「插件 → 添加插件」填写 `https://github.com/moutsea/dsh-desk-buddy`，启用后重启 DSH。也可使用下方完整 `.tgz` 附件链接或本地绝对路径，无需另装 Node.js、Electron 或启动 DSH Web。

- `darwin-arm64`：macOS Apple Silicon。
- `win32-x64`：Windows x64。
- `SHA256SUMS.txt`：两个完整插件包的校验值。

已有用户可在「设置 → 插件更新」检查并更新，升级后重启 DSH。旧版本迁移见 [插件说明](https://github.com/moutsea/dsh-desk-buddy/blob/main/plugins/dsh-girl/README.md)。

# 产品与交互方案

## 定位

dsh-desk-buddy 是一个独立 Agent 桌宠产品，当前提供 DSH 连接器。用户可独立打开应用并配置连接，也可通过完整 DSH 插件安装，由插件启动原生桌宠并自动绑定当前宿主。两种入口复用同一个桌宠组件和功能。其他 Agent 连接器尚未实现。

用户无需一直打开 DSH 主界面，就能看到任务进展、继续对话、对指定项目下达任务。陪伴感来自轻量、及时的反馈，不依赖模型持续生成台词。

DSH 继续承担执行引擎、模型配置、凭证、工具、审批、会话和持久化。用户关闭桌宠面板不影响任务；退出桌宠应用不终止 DSH 服务。

## DSH 插件入口

通过标准 DSH 插件命令安装一个包含原生桌宠组件的完整包。首次启用自动校验、解压和启动，服务地址从当前宿主读取。DSH 页面左下角“dsh-desk-buddy”打开管理卡片，可查看状态、启动、关闭、显示、隐藏、打开对话和切换自动启动。大小、表情和置顶仍在桌宠自身设置中，管理页不重复这些选项。

同一插件管理器的重复启动请求共用一个进程。手动关闭桌宠后保持关闭，用户可从管理页再次唤醒；自动启动设置只决定下次启用插件时是否启动。插件停用、卸载生效或宿主退出时关闭其管理的桌宠，宿主异常退出也会通过私有管道断开触发清理。不会终止 DSH 任务，也不会接管用户独立打开的桌宠。

插件模式自动锁定当前 DSH 地址，数据按所属 DSH profile 保存；独立模式继续手动配置，并使用原来的独立应用数据。完整插件内置余额桥接，不需要额外安装余额插件。当前支持 macOS 官方 DSH Desktop 0.2.1-rc.2 和 DSH Web 0.1.1-rc.2。Desktop 在插件页添加本地完整包，自动连接当前宿主，无需另外启动 Web 服务。

## 三种交互深度

1. 陪伴：平时只显示桌宠的动态角色，被点击时回应；鼠标悬停后才浮现“对话、表情、设置”三个气泡、余额和状态短句。移开鼠标后隐去控制，保留短暂宽限，方便移动到气泡。
2. 快捷对话：点击对话气泡，在桌宠身旁的同一透明窗口内展开对话框，默认小档 360 × 460；设置中可选中档 480 × 620 或大档 600 × 760。空间不足时自动适应屏幕，选择保存在本机并在重启后恢复。用户输入后发送给当前 DSH 会话。显示回复、工具调用摘要、执行状态及待回答事项。面板显示当前项目和会话，避免发错任务。
3. 会话管理：从对话标题旁打开已有会话列表，切换查看历史、新建会话、取消当前轮次、打开完整 DSH 界面。切换保留各个会话的输入草稿。列表同时显示运行和待回应状态。

“聊天”和“执行任务”共用输入入口，第一版没有独立的只读闲聊权限预设。因此所有消息都可能触发 DSH 工具，界面明确显示“使用 DSH 当前权限”。后续如增加陪伴专用会话，应通过 DSH 的受限 agent preset 落实工具限制，不能只靠一句提示词。

## 统一使用会话

聊天、规划和有明确目标的执行都对应 DSH 的 Session；目标、约束与进展属于会话内容，运行、等待、完成属于执行轮次的状态。界面只有“对话、表情、设置”三个入口，会话切换放在对话标题旁。已有会话直接读取 DSH，继续沿用其上下文与权限。

待回应数量显示在对话入口；其他会话等待回应时，对话内提供直达会话列表的提示。子代理待回应事项仍提供打开 DSH 的入口。

## 桌宠状态

优先级：连接失效 > 等待用户 > 新发生的错误（4 秒）> 新完成的庆祝（6 秒）> 正在执行的任务 > 完成后的开心/失败后的委屈 > 空闲。

多会话场景按全部普通会话聚合：任何会话等待用户时，桌宠提示等待回答；后台会话完成或出错时也触发短暂反应，之后回到正在执行的会话。聊天顶部头像始终跟随当前会话，底部状态保持真实执行结果。通过标题旁的会话列表可以定位。

状态由 DSH 事件驱动，动画只是表现层。读取与搜索显示学习，其他工具显示工作，文本输出显示正在回复。工具失败短暂震惊后恢复执行；整轮失败则震惊后委屈，错误文字持续保留。只有明确的 completed 才庆祝；取消、暂停、达到输出上限与未知结束原因不庆祝。网络中断不能被解释成任务完成。重连后重新加载任务列表、当前历史和待确认事项。打开应用时不把历史任务当成新完成。详细映射和时长见 [任务与表情联动](task-behaviour.md)。

完成时额外提供不依赖悬停的 6 秒动作提醒：桌宠跳跃庆祝，脚边显示任务名称；多个完成合并计数。固定表情和紧接着开始的新轮次不会掩盖这次提醒，到期后恢复原选择或当前状态。提醒沿用原窗口和位置，不自动展开对话、切换会话或抢焦点；动态效果关闭时保留静态反馈。失败、取消、重复及历史事件不产生成功提醒。

## 最小可用闭环

1. 用户启动 DSH Web 服务并连接桌宠。
2. 选择本机项目文件夹，新建会话。
3. 输入“看看这个项目，帮我……”。
4. 看到自己的消息、流式回复（宿主提供 chunk 事件时）、工具执行摘要。
5. 对审批或提问作出明确回答；可以取消当前轮次。
6. 完成后收到角色状态反馈，继续追问；也可从标题旁切换其他会话。

## 余额

余额来自 DSH 配套插件读取的 `DEEPSEEK_API_KEY`，表示这个 Key 的账号余额。多币种分别显示，不把美元和人民币相加。与模型供应商或当前会话不一致时，仍明确标注 DeepSeek Key 账号。首次失败显示具体原因；已有数据后失败标注旧数据与更新时间。

悬停余额旁显示 DeepSeek 官方 API 当前“峰时／谷时”：暖色表示峰时，绿色表示谷时，标签随北京时间自动切换，不依赖余额查询。悬停可查看适用范围与时段规则。峰时为周一至周五（节假日除外）09:00–12:00、14:00–18:00，其他时间为谷时；内置 2026 年节假日，未收录新年份的可能峰时明确标注估算。

第一版不计算“今日消耗”和“每轮人民币成本”：并发任务、多个客户端、动态价格和不同供应商会使余额差额或写死价格失真。之后优先接入 DSH 的官方用量投影，并区分估算与账单金额。

## 桌面行为

- 仅有一个透明原生窗口，启动只显示角色区域（默认 300 × 400，随大小设置适配），不自动展开内容。点击气泡才聚焦输入。
- 透明区域鼠标穿透，直接按住角色即可移动，移动超过 5 像素后认定拖动；轻点或轻微手抖仍保留摸摸互动。拖动时隐藏悬停控制，松开后恢复，且不触发点击表情。
- 松开后自动保存位置，重启后恢复。拖动时内容跟随，必要时切换左右方向，保留会话与草稿；根据鼠标所在显示器限制在可见区域，支持不同大小的桌宠。失焦或失去指针捕获时结束拖动，避免卡住。
- 内容自动选择桌宠左右空间更充足的一侧展开。正常屏幕上展开、切换、收起保持角色的屏幕坐标；空间不足时限制在当前显示器的可用区域。
- 再次点击当前气泡、右上角关闭或 Escape 收起内容，保留各会话草稿；会话列表直接显示在对话区域，Escape 先返回对话，再收起内容。托盘及快捷键也可恢复。
- 余额只随悬停气泡显示；设置中可主动查看详细余额与更新时间，不再常驻角色下方或对话底栏。
- 设置中可将桌宠大小调整为 50%–150%，每档 5%，提供恢复默认 100%。松开滑块、键盘调整或离开滑块后应用，保存并在重启后恢复。气泡与内容文字保持原大小；窗口边界和展开位置适配角色大小，空间允许时以脚底为基准调整，屏幕边缘限制在可见区域。
- 全部静态表情与动作帧按照主体可见身高和脚底锚点归一化，不用图片画布或姿态宽度决定角色大小。
- 第一版无主动语音和定期模型调用；不因闲置产生费用。
- 余额每分钟更新；事件流断线退避重连；失败有状态反馈。

## 后续扩展

当前视觉为 DeepSeek 娘：蓝色渐变长发、鲸鳍耳、鲸尾、呆毛和蓝白女仆装，界面随角色采用蓝白配色。内置 19 张表情与姿态，包括学习、工作、无聊和庆祝，自动跟随任务，也可以在表情页或右键菜单固定选择。自动模式下，点击比心、连续点击生气、悬停害羞；任务执行优先于空闲情绪。完整说明见 [角色文档](character.md)。

可替换角色包、更多动作、视线跟随、完成通知、快捷指令、拖入文件、模型选择、受限闲聊预设、可选托管 DSH 进程、独立安装包与开机启动。角色素材和语音需单独确认来源与授权。

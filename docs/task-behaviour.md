# 任务、对话与表情联动

常规状态表情在表情页选择“自动跟随会话”后生效。手动固定表情时保留选择，真实执行状态仍显示在文字里；桌宠的成功完成提醒会临时展示庆祝，6 秒后恢复固定表情。桌宠监听所有普通会话，对话顶部头像只跟随当前会话；无需额外请求模型来决定表情。聊天与有目标的执行都沿用同一个 DSH 会话入口。

| 真实事件/条件 | 角色动作 | 停留与恢复 |
| --- | --- | --- |
| `turn/start`、思考片段 | 托腮思考 | 等待下一阶段 |
| `tool/call`，工具名为 read/read_image/search/web_search/web_fetch 等 | 捧书学习 | 执行期间；很快完成的工具至少展示约 1.4 秒 |
| 其他 `tool/call`，如 bash/write/apply_patch | 敲电脑工作 | 执行期间，未知工具也按工作处理 |
| `assistant/chunk` 文本增量，或最终文本消息 | 开心、正在和你说话 | 到下一阶段；刚结束的短工具可能短暂保留动作 |
| 审批/问题待回答 | 歪头疑问 | 回答或取消后恢复 |
| `tool/result` 中 `tool-result.isError` 为 true，或结构化工具错误 | 震惊 | 4 秒后回到真实执行阶段；不把工具失败当作整轮失败 |
| `turn/end` 明确为 completed | 举手庆祝、轻跳和星星 | 庆祝 6 秒，再开心 6 秒，然后空闲 |
| `turn/end` 为 error | 震惊后委屈 | 震惊 4 秒，再委屈至结束后 20 秒；错误文字保留 |
| `host/agent-error` | 短暂震惊 | 执行中的任务可继续恢复；终止状态由宿主后续事件确认 |
| aborted/interrupted、blocked、max-tokens 或未知结束原因 | 犯困或疑问，文字显示停止/暂停 | 不触发成功庆祝 |
| 断线 | 睡觉，提示未连接 | 两条事件流都恢复后再跟随任务 |
| 空闲 1 / 2 / 4 分钟未互动 | 无聊 / 困困 / 睡觉 | 新任务立即唤醒；对话操作也重置空闲计时 |

启用空闲小情绪时，也会间隔展示吃饭、读书等生活动作。空闲读书不表示执行了学习任务，气泡会写“空闲时也要读点书”。关闭空闲选项后停止随机动作和自动无聊/犯困；任务联动继续生效。

## 多任务和事件顺序

连接失效和待回应事项优先。新错误短暂打断 4 秒，新成功庆祝 6 秒；之后恢复其他仍在运行的任务，不让旧错误一直遮住工作状态。只有没有运行任务时，继续展示完成后的开心或失败后的委屈。对话头像始终对应当前会话，不随其他会话的庆祝变化。

并行工具按 `callId` / `toolCallId` 匹配；其中任一个执行类工具仍在运行时显示工作，全是读资料类才显示学习。按会话 `seq` 忽略重复或倒序事件，重连不会重复触发同一轮庆祝。历史加载只投影消息和文字状态，不重放动作。列表轮询和 host running 提示不会覆盖正在学习/工作/回复的阶段。新一轮开始会清除上一轮情绪。

## 独立完成提醒

实时 `turn/end` 且原因明确为 `completed` 时，记录独立的 6 秒完成提醒。即使收起对话、鼠标移开或手动固定了表情，桌宠也会举手、跳跃，并在脚边短暂显示“任务名 完成啦！”。提醒不展开对话、不移动窗口，也不抢输入焦点。多个轮次在短时间内完成时合并计数，分别到期，避免提示排队很久。

完成提醒与执行状态分开保存，因此下一轮立即开工也会保留已发生的完成反馈；到期后恢复当前真实状态或用户固定的表情。断线、待审批及新错误的角色表现仍优先，已完成任务的文字提示独立显示。动态效果关闭或系统要求减少动态效果时，保留静态庆祝和文字提示。

提醒只接受通过序号去重的实时事件，启动、历史加载、列表刷新、失败、取消、暂停及未知结果均不生成成功提醒。提醒不持久化，重新连接或启动不会把历史完成当成新通知。子代理不单独触发提醒。

## 实现位置与协议依据

`shared/activity.mjs` 负责事件归约、工具分类、终止原因、时长和多任务优先级；`shared/expressions.mjs` 负责表情选择与手动固定；`shared/completion.mjs` 负责独立完成提醒的记录、去重、合并和到期。主进程只将实时事件送入归约器；同一透明窗口中的角色与对话头像用相同的时钟规则计算展示，对话页不会改写执行结果。

已对照本机 DSH `0.1.1-rc.2` 的 `@deepseek-ai/dsh-session` / `dsh-llm` 类型：工具失败字段在 `data.message.content[]` 的 `tool-result` 块内，关联字段是 `toolCallId`；结束原因以 `reason.kind` 为准。不从自然语言里的“失败”“完成”猜测任务结果。

新增立绘为内置 ImageGen 编辑生成，保存在 `public/characters/deepseek-girl/{learning,bored,celebrating}.png`；完整提示词和逐张路径见 [task-expression-prompts.json](task-expression-prompts.json)。

# 使用与开发指南

安装和升级见 [插件说明](../plugins/dsh-girl/README.md)，平台限制见 [平台支持与验证](platforms.md)。

## 日常使用

平时只显示桌宠，悬停后出现「对话、表情、设置」入口及余额。点击入口，在角色身旁展开面板；再次点击、右上角关闭或按 `Esc` 收起，草稿保留。`Command/Ctrl + Shift + Space` 可直接切换对话面板。

按住角色拖动，位置会自动保存。设置可调整桌宠大小（50%–150%）、窗口置顶、动画、闲置表情和对话框大小。小、中、大对话框分别以 360 × 460、480 × 620、600 × 760 为目标，空间不足时适配屏幕。

对话标题旁切换会话，加号新建会话，历史可向前加载。执行期间发送的消息进入 DSH 队列；停止按钮取消当前轮次，原有排队消息可能继续执行。审批和提问可以直接在对话框处理。对话框底部显示当前会话的模型，展开下拉即可切换，选择对下一回合生效；新会话先使用平台默认模型，外部只读会话不能切换。

收起面板后，进行中或待回应的会话显示进度气泡，预览工具命令、实时回复或待回应事项。多会话气泡和文字保持水平，后层沿右上方 45° 斜线等距错位叠放，始终最多显示 5 张，透明卡片也计入。悬停时指针所在的那张卡片变为不透明并亮出自己的关闭按钮，其他卡片为 90% 透明且只留标题；悬停不会切换会话，也不会挪动卡片位置，因此不会出现「去点 × 却被换走」的情况。用键盘浏览时，选中的卡片抽出并置顶。超过 5 个会话时，移开鼠标会折叠中间卡片，折叠的会话用方向键、Home / End 翻看，选中后按 Tab 可到它的 ×。点击任意可见卡片直达该会话，按回车打开当前选中的会话。桌宠贴近屏幕顶部时会少显示几张，避免挡住角色本身。任务结束后气泡继续保留并显示完成、停止或出错状态。点击气泡右上角的 × 只关闭显示，不会停止任务或删除会话；关闭后同一会话下次开始新任务时重新出现。气泡记录保留在当前桌宠进程中，重启后不会把旧历史批量弹出。成功完成时，桌宠庆祝并短暂显示任务名；失败、取消和历史加载不触发完成提醒。关闭桌宠不会取消 DSH 中已接受的任务。

## 用量与提示音

对话框显示当前会话累计 Token、输入缓存命中率和上下文占用，点击展开明细。输入包含未缓存输入、缓存读取和缓存写入；命中率为缓存读取 ÷ 全部输入。上下文属于单次请求占用，估算值带「≈」。未上报或无可计算样本时显示「—」，不据此推算费用。累计数据来自宿主，历史分页不会重复累加。

「设置 → 声音陪伴」可选择 8 种声线、试听、调节音量。点击「互动声音设置」打开弹窗，按互动、日常陪伴、任务与连接分组控制 13 类场景，也可逐项试听；更改自动保存，点击弹窗外、右上角关闭按钮或按 Esc 返回设置页。默认音量 35%；开工、入睡、搬家和恢复连接默认关闭，其他场景默认开启；设置在重启后保留。语音离线播放，切换声线、静音或关闭对应场景会停止相关声音。

1.8 秒内点击角色 5 次会触发生气反应，并说「慢一点啦，哼！」；持续连点只说一次。工作状态或固定表情盖过互动表情时，不会触发生气语音。旧设置若关闭了摸摸声音，升级时也会默认关闭连点小脾气，之后可独立调整。

审批和提问到来时提醒一次，重连不重复提醒同一事项；任务失败会提醒，主动停止和单次工具报错保持安静。后台普通会话也会提醒，子代理不单独发声。多个事件同时到来时优先播放待回应或出错提醒，避免叠音。

轻点角色回应，摸摸、闲置、开始任务、任务完成、需要回应和任务出错各有三句台词随机轮换，避免连续重复。悬停看她 8 秒会害羞；闲置约 4 分钟入睡后，点击会叫醒；10 分钟没互动后再点，会优先欢迎回来，只说一句。拖到新位置放下可开启搬家回应，小幅抖动、拖回原处或取消拖动不触发，至少间隔 30 秒。恢复连接可选在断线至少 10 秒、稳定连上 3 秒后提醒。任务成功完成时说「做好啦」。闲置约 75–105 秒后偶尔招呼，之后至少间隔 2 分钟；工作、待回应、展开面板、隐藏和睡着时保持安静。音频资源、来源与重新生成方式见 [语音包说明](voices.md)。

## 余额

完整桌宠插件已内置余额桥接，通过 DSH 凭证服务查询 DeepSeek 官方余额，不向桌宠传递 API Key。余额属于该 Key 对应的账号，与第三方模型供应商的余额无关。

独立运行时，可单独安装轻量余额插件并重启 DSH Web：

```sh
dsh plugin --profile web add link:/absolute/path/to/dsh-girl/plugins/dsh-girl-bridge
```

已使用完整插件时无需再装余额插件。峰谷倒计时按北京时间显示 DeepSeek 官方 API 计价时段，跨周末和已收录节假日计算；未知年份会标明估算，不代表第三方供应商的实际计费。

## 独立运行

需要 Node.js 22.12+、npm 和 DSH Web：

```sh
npm ci
dsh web --host 127.0.0.1 --port 3080 --no-open
npm run dev
```

打开设置连接 `http://127.0.0.1:3080`，选择项目目录后新建对话。官方 DSH Desktop 通过插件自动接入，无需另外启动 Web 服务。`npm run dev:web` 仅预览界面，不提供桌面连接能力。

```sh
npm run pack:plugin  # 在目标系统生成含原生组件的完整 .tgz

```

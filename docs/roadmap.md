# 开发阶段与验收

## 第一阶段：独立桌面入口

范围：透明桌宠、双窗口、托盘、快捷键、位置记忆、连接设置、余额插件、任务列表、项目目录、新建会话、历史分页、发送、流式事件、取消当前轮次、审批与提问、断线恢复。

验收重点：

- DSH 未启动时显示离线，发送不可用。
- 新会话关联用户选定目录，发送失败保留草稿，不自动重发。
- 历史与 WebSocket 事件到达顺序变化不会重复消息或丢掉新事件。
- 任务完成、取消、错误、等待用户明确区分。
- 重连恢复历史和待确认事项，网络断开不误报完成。
- 关闭面板不退出桌宠、不取消任务；托盘可以恢复窗口。
- 余额缺插件、缺凭证、官方接口失败时明确展示；多币种不相加。

## 第二阶段：陪伴与效率

替换角色包与动作映射、完成系统通知、快捷指令、近期项目、模型选择、受限闲聊预设、文件附件。先完善真实任务反馈，再增加动画细节。

## 第三阶段：发布与更独立运行

签名安装包、启动管理、可选 DSH 子进程托管与健康检查、版本兼容矩阵、跨平台实机验收。DSH 进程托管需明确 home/profile 和端口所有权，不能结束用户原有 DSH 进程。
